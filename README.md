# ねことまいにち — 静的配布サイト

ビルドや外部ライブラリは不要です。`site/` の内容を静的ホスティングの公開ディレクトリへ配置してください。GitHub Pagesの場合もこのディレクトリの内容を公開対象にします。

## ローカル表示

`index.html` をブラウザで開けます。静的サーバーを使う場合は、siteディレクトリで実行してください。

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。終了は Ctrl+C。

## APKとバージョン

`config.js` の `apkUrl` を編集してください。`version` は配布情報として設定ファイル内に保持していますが、ページには表示しません。APK未設定時はボタンを無効表示にします。例えばAPKをこのディレクトリに置いた場合はそのファイル名を相対パスとして設定できます。別サーバーの場合は実際のHTTPS URLを設定してください。別サーバーへのリンクは、サーバーの設定によってブラウザ内で開く場合があります。

## スクリーンショット

`assets/screenshots/` に `home.png`、`tasks.png`、`shopping.png` を置くと読み込まれます。未配置・読込失敗時はプレースホルダーを維持します。画面幅に合わせて縮小し、実画像の縦横比を保持します。

2〜4枚へ変更する場合は `config.js` の `screenshots` を編集してください。各項目の `src`、`alt`、`caption` が画像パス、代替テキスト、表示名です。タブレット画像も同様に設定できます。

## ファーストビューの画像

`assets/images/` に画像を置き、`config.js` の `heroImage` と `heroAlt` を設定してください。空欄・読込失敗時はCSSで描いた部屋と黒猫を表示します。

## 公開前の準備

実際の配布用APK、そのバージョン番号、必要に応じてアプリのスクリーンショット（2〜4枚）、静的ホスティングの公開先を用意してください。APKリンクを設定したらAndroid端末でダウンロードとインストールを確認してください。
